# T06 · Build phase · 15 pts

**Goal:** serve a small menu from memory.

- Model `MenuItem(id, name, price, stock)` and seed five items on boot.
- `GET /menu` — list all items.
- `GET /menu/{id}` — return one item or `404` for an unknown id.
- `POST /menu/{id}/reserve` — accept `{ qty }`, decrement stock (reject when stock runs out). No auth yet.
- Run `scripts/verify-T06`.

**Acceptance:** all three endpoints work on 8081, an unknown id returns 404, and reserve decrements stock.

**Hints:**
1. A `ConcurrentHashMap<Long, MenuItem>` is the store; seed it in a `@PostConstruct` or `ApplicationRunner`.
2. Return 404 via `ResponseEntity.notFound().build()`.
3. Reserve > stock should fail cleanly — the erroring contract is settled in T10.
