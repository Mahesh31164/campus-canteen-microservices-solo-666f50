# T02 · Configure phase · 10 pts

**Goal:** turn discovery-server into a service registry.

- Add `@EnableEurekaServer` to `DiscoveryServerApplication`.
- Set `register-with-eureka: false` and `fetch-registry: false` for the server itself.
- Start only discovery-server and open the dashboard on 8761.
- Remove both flags, watch the server try to register with itself, then put them back.
- Run `scripts/verify-T02`.

**Acceptance:** the dashboard loads on 8761 with an empty registry.

**Hints:**
1. One annotation on the main class is the whole server.
2. A server registers with itself unless you tell it not to — that's what the two `false` flags prevent.
3. The dashboard is the registry UI at the server's own HTTP port.
