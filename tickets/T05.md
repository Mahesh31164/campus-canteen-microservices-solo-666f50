# T05 · Build phase · 15 pts

**Goal:** implement login and validate with zero cryptography.

- Seed three hardcoded users (username, password, name, userId): `alice`, `bob` and `carol`, all with password `password`.
- `POST /auth/login` — match the credentials, issue a random `UUID`, store it in a `ConcurrentHashMap<token, User>`, return `{ token, userId, name }`.
- `GET /auth/validate?token=` — look the token up; return `{ userId, name }` or `401`.
- Run `scripts/verify-T05`.

**Acceptance:** login returns a token, validate returns the user, and a garbage token returns 401.

**Hints:**
1. A `Map<token, User>` is the whole session store.
2. `UUID.randomUUID()` is your token.
3. Return `401` from a `ResponseEntity`, not an exception the caller must decode.
