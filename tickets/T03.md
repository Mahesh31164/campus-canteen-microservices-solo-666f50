# T03 · Configure phase · 10 pts

**Goal:** point gateway, auth, menu and order at the registry and watch the heartbeat do its job.

- Add the eureka-client dependency to all four service YAMLs via `defaultZone`.
- Set `prefer-ip-address: true` where needed and understand what it does.
- Boot everything and confirm four instances appear on the dashboard.
- Kill one service and watch it drop off within the eviction window.
- Run `scripts/verify-T03`.

**Acceptance:** the dashboard lists four instances; killing one drops it off within the eviction window.

**Hints:**
1. Registration is a heartbeat, not a config file.
2. `defaultZone` is the URL of the Eureka server's standard endpoint.
3. If the dashboard shows an instance as unavailable, check `prefer-ip-address` and the hostname.
