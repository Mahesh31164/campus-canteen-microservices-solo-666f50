# T04 · Build phase · 10 pts

**Goal:** create the shared contracts every service compiles against.

- Write the nine records in `common-contracts` under the empty `dto` package — the whole contract surface of the canteen: `LoginRequest` (login body), `AuthResponse` (token, userId, name), `ValidateResponse` (userId, name), `MenuItem` (id, name, price, stock), `ReserveRequest` (qty), `OrderRequest` (menuItemId, quantity), `Order` (stored order), `OrderDetailResponse` (order plus buyer name and item name it does not own), and `ApiResponse<T>` (the envelope public endpoints return).
- Wire `common-contracts` into the auth, menu and order service `build.gradle` files.
- Run `./gradlew build`.
- Run `scripts/verify-T04`.

**Acceptance:** everything compiles against the module; no entities, no logic, no state in the shared module.

**Hints:**
1. Records are Java 16+ — you are on 21; no getters/setters boilerplate.
2. The shared module holds only DTOs; business state stays in each service's own memory.
3. Services share contracts. They never share code or data.
